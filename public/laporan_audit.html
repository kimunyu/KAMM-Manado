LAPORAN AUDIT KEAMANAN, AUTENTIKASI & OTORISASI (P0-1)

Aplikasi: KAMM-Manado | Platform: React + TypeScript + Firebase Firestore | Status: AUDIT ONLY

A. Executive Summary

  1. Firestore Rules Terbuka Penuh: File firestore.rules disetel ke allow read, update, write: if true; untuk seluruh dokumen.
  2. Ketiadaan Firebase Authentication Resmi: Tidak ada token JWT, tidak ada request.auth, dan tidak ada verifikasi sesi server-side.
  3. Autentikasi Bersifat Client-Side Custom: Login mencocokkan string username dan password di memori browser.
  4. Penyimpanan Password Plain Text: Password disimpan tanpa enkripsi di Firestore dan localStorage.
  5. Privilege Escalation Instan: User dapat mengubah rolenya menjadi SUPER_ADMIN langsung dari browser console.
  6. Data Leakage Real-Time: Seluruh koleksi Firestore disinkronkan ke seluruh user tanpa query scoping.
  7. Otorisasi 100% di Frontend: Pembatasan cabang, posko, KD AO, dan batas 48 jam hanya ada di React UI.
  8. Role RM Belum Memiliki Pembatasan Area: Entitas Area belum ada di model user sehingga RM melihat seluruh nasional.
  9. Inkonsistensi Skema Data: Perbedaan penamaan field kd_cabang/kd_posko vs kd_cab/kd_pos.
  10. Tidak Ada Server API Proxy: Aplikasi langsung berinteraksi dari client ke Firestore publik.
